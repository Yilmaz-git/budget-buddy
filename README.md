
# Budget Buddy – Personal Finance Tracker

Budget Buddy is a personal finance tracking application developed with React and JavaScript. It helps users manage their income and expenses, monitor their balance, and visualize their financial activities.

## Features

- Dashboard with total balance, income, and expenses
- Add, view, edit, and delete transactions
- Separate income and expense categories
- Currency selection (TRY, USD, EUR, GBP)
- Statistics dashboard with charts
- Monthly income and expense analysis
- Expense distribution by category
- Data persistence using LocalStorage

## Technologies Used

- React
- JavaScript
- Vite
- Bootstrap 5
- CSS
- Chart.js
- React Chart.js 2
- LocalStorage

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Yilmaz-git/budget-buddy.git
   ```

2. Navigate to the project folder:

   ```bash
   cd budget-buddy
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Usage

Open the application in your browser using the local URL provided by Vite.

Use the Dashboard to monitor your finances, Transactions to manage financial records, and Statistics to analyze your spending and income.

## Currency Note

Currency selection changes the displayed currency format. It does not perform real-time currency conversion.
